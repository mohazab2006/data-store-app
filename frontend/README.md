# Frontend — Data Store App

Vite + React + TypeScript UI for the `/api/users` REST API.

See the **repository root** `README.md` for full project context.

## Commands

```bash
npm install
npm run dev
```

Dev server defaults to **http://localhost:5173** (matches backend CORS).

Optional: copy `.env.example` to `.env` and set `VITE_API_BASE_URL` if the API is not at `http://localhost:8080`.

```bash
npm run build
```
